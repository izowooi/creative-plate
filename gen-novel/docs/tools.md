# 집필 도구 선택

기준일: 2026-09-05. 기본은 현재 프로젝트 대화에서 선택한 GPT-6 Astra와 로컬 Markdown이다.
별도 구독이나 API 연동 없이 먼저 작가 취향과 하루 작업 흐름을 정착시킨다.
프로그램은 모델 ID를 하드코딩하거나 다른 모델로 바꾸지 않는다. 실제 집필 모델은 대화에서 선택한다.

[OpenAI 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-6-astra)에
GPT-6 Astra가 등재되어 있음을 확인했다. 문서 등재가 개별 계정의 이용 권한이나 예약 실행을 보장하지는 않는다.
[공식 AGENTS.md 문서](https://learn.chatgpt.com/docs/agent-configuration/agents-md)를 참고해
작업 지침과 작품 자료의 경로를 구분했다. AGENTS.md 자체가 소설 데이터베이스나 자동 기록 프로세스는 아니다.

NovelAI는 이미 구독 중인 선택 도구로 남긴다. 이번 구현은 그 서비스의 지원 언어·API·요금을 전제로 하지 않는다.
필요하다면 승인된 context를 사람이 옮겨 초안을 비교하고, 결과를 새 run의 draft에 넣은 뒤 같은 검토 절차를 거친다.
외부 서비스에 작품 자료를 보내는 것은 별도 선택이다. 현재는 연결하거나 전송하지 않았다.
RisuAI의 lorebook 아이디어는 ID·키워드·관련 자료 조회에 반영했으며, RisuAI 설치나 포맷 호환을 요구하지 않는다.

현재 CLI는 자료 준비와 승인 기록을 자동화한다. 실제 문장 생성은 이 대화의 AI가 수행한다.
아침 요청 한 번으로 이 세션에서 준비→집필→검토까지 수행할 수 있으나,
앱이 종료되어도 계속 실행되는 무인 worker나 예약 스케줄러는 포함하지 않는다.
그런 운영이 필요해지면 공식 API 권한·비용 상한·실행 장치·실패 알림을 정하고 별도 구현한다.
지금 목적에는 이 프로젝트를 연 AI와 하루 한 번 대화하는 방식이 바로 사용할 수 있는 경로다.
