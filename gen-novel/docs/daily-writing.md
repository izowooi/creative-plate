# 처음 시작하는 매일 집필

작가님은 이야기의 방향과 취향을 정하고, AI는 그 방향을 실제 장면과 문장으로 만든다.
좋은 피드백은 전문적인 편집 용어가 아니라 “이 아이가 좋다”, “여기는 지루하다”, “이 장면을 더 보고 싶다”에서 시작한다.
완벽한 설정집이나 긴 프롬프트를 먼저 만들 필요는 없다.

## 오늘 할 일: 첫 화를 읽고 감각 잡기

[1화 「불을 끄는 순서」](https://gen-novel-reader.izowooi.workers.dev/read/?book=embers&episode=ep-0001)를
휴대폰에서 편한 글자 크기로 읽는다. 아직 퇴고 전 초안이며, 2화는 작성하지 않았다.
읽은 뒤 아래 세 가지 중 답할 수 있는 것만 이 대화에 적는다.

1. 에단이 내가 생각한 주인공처럼 느껴졌는가?
2. 가장 좋았던 장면과 읽다가 느려졌던 부분은 어디인가?
3. 다음 화에서 더 보고 싶은 것은 가족의 일상, 마법 재능, 새로운 인연 중 어떤 장면인가?

“잘 모르겠어. 네가 편집자로서 아쉬운 점 세 가지를 짚고 수정해 줘”라고 해도 된다.
처음에는 세계 전체보다 첫 화의 주인공과 말투가 내 취향인지 확인하는 일이 더 중요하다.

## 첫 수정 요청 예시

> 1화를 읽었어. 아버지가 빵을 나눠 주는 장면이 좋았어.
> 에단은 조금 더 장난꾸러기였으면 좋겠고, 보온함 설명은 조금 줄여 줘.
> 기존 초안을 남겨 두고 새 버전으로 고쳐 줘. 아직 확정하지는 말아 줘.

AI는 새 버전의 원고를 만들고, 바뀐 내용에 맞춰 요약·인물 상태·복선을 정리한다.
작가님이 직접 고친 문장이 있으면 그것을 붙여 넣어도 좋다.
예시의 취향은 선택지가 아니라 요청하는 방법을 보여 주는 예이며 작품에 자동 반영하지 않는다.

## 마음에 들면 확정하고 다음 화로

> 지금 검토한 1화 버전의 원고와 기억 변경안을 확정해 줘.
> 이어서 2화 초안을 써 줘. 소년의 재능은 조금 드러나되 아직 능숙한 마법사가 되지는 않게 해 줘.

여기서 확정은 “다음 이야기가 믿고 이어받을 기준”을 정하는 것이다.
Git 공개나 DB 업로드만으로 원고가 확정되는 것은 아니다. 초안도 사이트에서 읽을 수 있다.
나중에 확정 원고를 바꾸고 싶다면 먼저 알려 주면 된다. 이미 이어 쓴 회차에 미치는 영향도 함께 확인한다.

현재 2화 기획은 「고장 난 것은 한 군데가 아니다」다.
에단이 감각만으로 고장을 다 이해했다고 생각했다가, 마법에는 지식과 배움도 필요함을 깨닫는 작은 사건이다.
이 기획은 변경 가능하다. 1화의 취향을 확인한 뒤 이어 쓰는 순서를 추천한다.

## 매일의 리듬

| 때 | 작가님 | AI |
|---|---|---|
| 아침 | 오늘 보고 싶은 장면이나 감정을 한두 문장으로 요청 | 관련 설정·앞 회차 확인, 초안 집필, 검토와 기록 |
| 저녁 | 모바일에서 읽고 좋았던 점/바꿀 점 전달 | 새 버전 작성, 요약과 다음 상태 갱신 |
| 만족할 때 | 해당 버전 확정 요청 | 최종본으로 기록하고 다음 회차의 기준으로 사용 |
| 가끔 | 3~5화가 쌓이면 전체 느낌 전달 | 중복 장면·느린 전개·복선과 취향을 함께 점검 |

소재가 생각나지 않으면 “앞 회차와 장편 기획에 맞춰 오늘 이야기 세 가지를 제안해 줘”라고 요청한다.
쉬고 싶으면 며칠 건너뛰어도 된다. 돌아왔을 때 “현재까지 이야기와 다음 선택을 짧게 알려 줘”라고 하면 된다.
AI가 대부분의 문장을 써도, 무엇을 좋아하고 어떤 방향으로 고칠지 결정하는 역할은 작가님에게 있다.

## 내가 신경 쓰지 않아도 되는 것

AI가 원고·설정·요약·요청 기록을 관리하고 Git에 commit·push한다.
push 후 GitHub 자동 작업이 Supabase에 반영한다. 작업 완료 뒤 사이트를 새로고침하면 새 회차를 읽는다.
화면에서 DB를 직접 수정하거나 파일·테이블 이름을 외울 필요 없다.
동기화가 실패하면 AI에게 “방금 원고가 사이트에 안 보여. 동기화를 확인해 줘”라고 하면 된다.

현재 읽던 위치와 글꼴 설정은 휴대폰/맥북 각각에 저장된다. 기기간 위치 동기화나 자동 예약 집필은 없다.
새 작품을 시작할 때는 “새 소설을 하나 시작하고 싶어”라고 말하면 AI가 별도 작품 ID와 설정·원고 폴더를 준비한다.
