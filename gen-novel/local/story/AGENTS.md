# L4 AGENTS.md — 작품 자료

프로젝트 `../AGENTS.md`의 집필·승인 절차를 따른다. 이 파일은 작품 자료를 다룰 때의 규칙이다.
`story/`는 템플릿이고 실제 집필 자료는 `novel.py init`으로 복사한 `local/story/`다.
복사본에서 부모 프로젝트 지침은 `../../AGENTS.md`로 찾는다. 상대 경로 깊이에 유의한다.

- 새 인물과 장소는 작가의 답변에서 출발한다. AI 제안과 사용자 확정값을 명시한다.
- 제목, 인물 이름, 핵심 배경, 첫 사건이 미정일 때 샘플을 실제 정사로 확정하지 않는다.
- 카드에는 ID, 별칭, 불변 특성, 현재 사실, 비밀/지식 범위, 관계 ID, 근거 회차를 둔다.
- 위치 카드에는 기능, 지형, 인접 장소·이동 시간, 감각 단서, 관련 인물을 쓴다.
- index.json의 id는 고유하며 path는 같은 자료 폴더 안 Markdown이다. requires는 존재하는 ID만 참조한다.
- 초기 핵심 설정은 local/story에서 편집한다. 회차 확정 이후 기존 lore 수정은 run의 updates/<id>.md 전체 대체안으로 제출한다.
- 실제 최신 정사는 초기 카드와 확정 회차 updates의 누적 결과다. CLI context에서 적용 결과를 확인한다.
- 인물의 지식과 독자의 지식을 구분한다. 시간·위치·소지품·부상·관계 변화는 다음 상태 snapshot에 남긴다.
- 새 설정 때문에 기존 원고와 충돌하면 해당 원문을 찾아 작가에게 제시한다. 원고를 몰래 다시 쓰지 않는다.
- 막대한 세계사를 먼저 생성하지 않는다. 다음 회차에 필요한 카드만 구체화한다.
- 작가의 개인 답변·원고·기록을 배포용 story 템플릿에 옮기지 않는다.
