# 작가 결정과 작업 권한

ID: author-policy. 출처: local/interviews/2026-09-05_작가인터뷰_답변원본.md 8·9번(프로젝트 기준 경로).
최신 답변은 interviews/01-author.md에도 있다. 예전 빈 local/author-answers.md를 답변으로 취급하지 않는다.

작가는 큰 방향을 제시하고 AI가 대부분을 집필한다. 이름·조연·사건뿐 아니라 핵심 배경,
죽음·관계 변화도 AI가 제안하여 써도 된다고 명시했다. 이런 선택마다 질문으로 멈추지 않는다.
마음에 들지 않는 부분은 작가가 후속 가이드로 고친다. 작가가 정한 핵심 방향은 보존한다.
기존 지침의 “핵심 설정 미정이면 질문”은 현재 위임 범위에서 초안 작성을 막는 규칙이 아니다.
최종 회차 확정은 기존 저녁 퇴고 절차를 따른다. 자유 집필 권한을 확정 승인으로 위조하지 않는다.

API 없이 현재 대화에서 집필한다. 프롬프트·답변 요약은 날짜·한국 시간·한글 주제로 기록한다.
사람이 찾는 index.md와 CLI의 index.json을 함께 유지한다. 필요한 관련 자료만 읽는다.
작가는 작품과 기록을 Git에 넣고 싶어 한다. 확인 당시 원격이 PUBLIC이어서 private 전제가 성립하지 않는다.
공개 범위 답변 전 작품과 인터뷰를 push하지 않는다. 인증 정보는 어떤 보관 선택에도 포함하지 않는다.
