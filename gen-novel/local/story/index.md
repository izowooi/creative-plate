# 작품 자료 찾아보기

최신 기준: 2026-09-05 작가 인터뷰 반영. CLI의 기계용 색인은 [index.json](index.json).
원고에 쓰인 사건의 확정 여부는 [현재 상태](state.md)와 local/final에서 확인한다.
카드에 표시된 “작가 확정”과 “AI 작업안”을 구별한다. 검색 결과가 없으면 과거를 지어내지 않는다.

| ID | 문서 | 언제 읽나 |
|---|---|---|
| premise | [작품의 약속](core/premise.md) | 매번, 목표와 큰 방향 |
| style | [문체](core/style.md) | 매번, 시점·수위·길이 |
| author-policy | [작가 위임 범위](core/author-policy.md) | 매번, 질문·집필·보관 정책 |
| hero | [에단](characters/hero.md) | 매번, 11살 학생의 관찰과 선택 |
| family | [가족](characters/family.md) | 아버지·동생·대장간 일상 |
| heroine | [리아나](characters/heroine.md) | 공주/학교 편; 아직 만나지 않음 |
| world | [기본 세계](world/foundation.md) | 매번, 여섯 왕국과 제국 |
| hometown | [브렌](world/hometown.md) | 고향·시장·빵 장수 네라 |
| magic | [마법](world/magic.md) | 감응·마도구·안전·성장 제한 |
| academy | [학교](world/academy.md) | 진학·선발·수업 |

관련 ID도 함께 읽고, 새 카드를 만들면 이 표와 index.json을 동시에 갱신한다.
전체 읽기를 요구하지 않는다. 예: 공주가 없는 고향 회차에 heroine 카드는 자동 포함하지 않는다.
