## 보관

기록 파일은 한국 시간의 날짜·시각·한글 제목을 사용한다. 내부 run 파일은 CLI 호환을 위해 draft.md 등 고정 이름이다.
이 안내에서 한국어 제목으로 바로 찾아 읽을 수 있다. 기존 파일을 일괄 이름 변경해 참조를 깨뜨리지 않는다.
현재 GitHub 모노레포는 PUBLIC으로 확인됐으므로 작품과 작성된 인터뷰의 push는 공개 범위 답변 전 보류한다.
인터뷰 원본은 사용자 파일 그대로 남겨 두었다. 저장소 전체의 공개 설정은 임의로 바꾸지 않았다.
