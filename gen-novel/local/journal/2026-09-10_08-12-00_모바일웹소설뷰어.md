기왕이면 네이버 시리즈 웹소설 앱 처럼 만들면 좋겠어요.
배포는 제가 따로 할게요. 기왕이면 next.js + tailwind 로 만들어주세요.
목적은 제가 만든 웹 소설을 편하게 모바일로 보는 것이에요.
디비는 현재 supbase 연결이 끊겨 있어요. 로컬로 해주세요. 아마 나중에는 cloudflare 나 supabase 로 할거 같아요.
혹시 git 공개라서 git 을 쓸 수 있다면 이것도 좋을 것 같아요.

## 구현과 결정

- gen-novel/web에 Next.js + TypeScript + Tailwind 앱을 구성했다. 앱 이름은 책갈피.
- 기존 Git의 원고를 빌드 시에 읽고 서재·작품·회차·읽기 페이지로 정적 출력한다.
- 확정본을 우선하고 초안만 있는 회차는 최근 작성된 초안을 표시한다. 현재 1화는 초안이다.
- 글자 크기, 줄 간격, 배경 3종, 고딕/명조, 읽기 도구 숨김, 회차 이동 및 문단 기준 이어 읽기를 제공한다.
- 취향과 읽던 위치는 기기별 localStorage이며 Supabase/API key/외부 DB 연결은 없다.
- 원고 갱신은 Git commit/push 후 다시 빌드하여 반영한다. Cloudflare 정적 배포 또는 미래 DB 교체 방법을 web/README.md에 남겼다.
- Sites 제작 스킬을 참고하되 사용자 지정 Next.js와 배포 제외를 우선했다. 읽기 중심 앱이므로 WebMCP 작업 도구는 추가하지 않았다.

## 검증

- 원고 선택/확정본 해시/빈 초안/경로 경계/설정 복원에 관한 9개 테스트 통과.
- Next.js build와 TypeScript 검증 통과. 정적 페이지가 web/out에 생성됨.
- 로컬 서재 미리보기를 열었다. 브라우저 클릭·모바일 실기기 시각 검증은 별도로 수행하지 않았다.
- 사용자 요청에 따라 배포하지 않는다. 검증 서버는 종료한다.
