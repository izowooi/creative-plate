[앱]
가칭: 바로 소음계
플랫폼: iOS 17 이상, iPhone 중심, SwiftUI

[목표]
사용자가 측정 버튼을 누르고 마이크 사용을 허용하면 즉시
소리의 입력 레벨을 확인하는 무료 도구를 만든다.
숫자를 그럴듯하게 보여주기보다 측정 단위와 한계를 정직하게 표시한다.

[필수 기능]
- 현재 레벨을 큰 숫자로 표시한다.
- 단위, 보정 상태, 측정 시간, 시작/정지 버튼을 첫 화면에 둔다.
- 약 100ms 간격으로 갱신하고 최근 60초 그래프를 표시한다.
- 명시한 RMS 구간의 최소/최대와 세션 전체 에너지 평균을 제공한다.
- 수동 보정 프로필 생성·선택·초기화를 지원한다.
- 종료 후 요약과 CSV 공유를 제공한다.
- 원음은 녹음·저장·전송하지 않는다.

[측정에서 절대 지켜야 할 조건]
- PCM의 dBFS와 물리적 음압 dB SPL을 구분한다.
- dBFS에 임의의 상수를 더해 실제 소음처럼 표시하지 않는다.
- 유효한 보정이 없으면 '상대 입력 레벨 · dBFS'와
  '미보정: 실제 소음 dB SPL이 아닙니다'를 명확하게 표시한다.
- 수동 보정 결과는 '보정 기반 추정치'로 표시한다.
  한 지점 보정이 모든 주파수와 레벨의 정확도를 보장하지 않음을 알린다.
- 보정 프로필에 참조 계측기 값, 측정 조건, 가중 설정, 날짜,
  마이크/입력 경로, 샘플레이트, 세션 설정을 기록한다.
- 입력 조건이 달라지면 이전 보정을 무효화한다.
- 참조 계측기와 앱의 가중 방식이 다르면 동등한 교정으로 취급하지 않는다.
- A-weighting 필터와 검증을 구현하지 않았다면 dBA라고 표시하지 않는다.
- 검증된 기종별 기본 보정값이 없으면 만들어 내지 않는다.
- 청력 진단, 아이에게 안전하다는 판정, 안전한 노출 시간,
  법적 계측·국제 규격 적합성은 주장하지 않는다.

[기술 구현]
- AVAudioEngine 입력 tap과 AVAudioSession을 사용한다.
- 실제 지원되는 적절한 측정 모드와 입력 포맷을 확인한다.
- 기본은 내장 마이크이며 활성 입력 장치를 화면에 표시한다.
- RMS와 dBFS 계산을 순수 함수로 분리한다.
- 에너지 평균은 제곱합/샘플 수로 계산한다.
  dB 값을 단순 산술평균하지 않는다.
- 0 입력, NaN, 무한대, clipping을 처리한다.
- 오디오 콜백에서 파일 쓰기, 무거운 작업, UI 갱신을 하지 않는다.
- 그래프 버퍼와 저장 데이터가 무한히 증가하지 않게 한다.
- 시작/정지 연타, 중복 tap, 권한 거부, 오디오 중단,
  백그라운드 전환, 입력 변경을 처리한다.
- 정지/백그라운드에서는 마이크와 오디오 세션을 해제한다.
- CSV에도 단위, 보정 여부, 입력 조건을 포함한다.

[검증]
- 합성 신호 진폭을 절반으로 줄이면 약 6.0206dB 감소하는지 테스트한다.
- 동일 시간 -40dBFS와 -60dBFS의 에너지 평균이
  약 -42.9671dBFS인지 테스트한다.
- 보정 조건 변경, 무음, clipping, 중복 시작/정지를 검증한다.
- 실기기와 참조 계측기 비교는 별도 수동 검증 계획을 작성한다.
- 시뮬레이터 빌드 성공을 실제 음압 정확도 검증으로 보고하지 않는다.
