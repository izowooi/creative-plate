# 스키타이 문명

## 개요

스키타이는 고대 그리스인이 주로 흑해 북쪽 초원의 이란계 언어 사용 집단을 부른 이름이며, 유라시아의 모든 기마 유목민이나 하나의 통일 제국을 뜻하지 않는다. 아시리아·페르시아 문헌의 사카, 중앙아시아와 알타이의 여러 ‘스키타이계’ 고고 문화는 말 장비·무기·동물양식 같은 특징을 공유하지만 서로 다른 정치 공동체였다. 기록 대부분이 그리스·아시리아·페르시아 등 외부인의 시선에서 나왔고, 헤로도토스의 풍습 설명도 고고학과 대조해 읽어야 한다. 기원전 9~8세기 무렵 중앙 유라시아에서 서쪽으로 이동한 여러 집단이 흑해 북부 초원에 자리 잡고 킴메르 세력을 대체했다. 기원전 7세기에는 캅카스를 넘어 서아시아 전쟁과 약탈·동맹에 참여했고, 이후 다시 폰토스 초원으로 중심을 옮겼다. 말 사육과 계절 이동, 활을 사용하는 기마전은 중요했지만 모든 주민이 끊임없이 이동한 전사는 아니었다. 강 유역에는 농경 공동체와 거점이 있었고 곡물·가축·노예를 흑해의 그리스 식민도시에 공급하며 포도주·금속공예품을 들여왔다. 왕족 쿠르간의 금속품은 초원 장인과 그리스 공방의 기술·도상이 만난 결과이며, 화려한 무덤이 평민의 일상을 그대로 대표하지 않는다. 기원전 6세기 말 다리우스 1세의 원정에 맞섰고, 기원전 4세기 아테아스 시대에는 다뉴브와 크림 일대의 왕권이 강해졌다. 기원전 3~2세기 사르마티아계 집단의 이동으로 폰토스 초원의 지배권을 잃었지만 크림과 하류 드니프로의 후기 스키타이 정치체는 기원후 수세기까지 존속했다. 중세 이후 ‘스키타이’는 실제 계통과 무관한 북방 집단을 부르는 문학적 이름으로 남았다. 현대 여러 국가가 고고 유산을 국민의 직접 조상으로 독점하면 광대한 초원의 이동성과 혼합을 왜곡한다.

## 게임에서 다시 보기

‘초원의 사람들’은 경기병이나 사카 궁기병을 만들 때 한 부대를 더 주고, 쿠르간과 토미리스의 처치 회복은 기마·무덤·전사 여왕 이미지를 극대화한다. 그러나 토미리스가 다스린 마사게타이는 고대 자료에서도 폰토스 스키타이와 같은 집단이라고 확정되지 않는다. 여성 무덤과 무기는 성별 역할이 그리스보다 달랐음을 시사하지만 모든 여성을 전사로 낭만화할 수도 없다. 두 배로 복제되는 기병은 초원 사회의 농경·교역·가족 노동과 정치적 차이를 가린다.

## 핵심 연표/사실

- 기원전 9~8세기: 여러 기마 목축 집단의 폰토스 초원 이동
- 기원전 7세기: 캅카스를 넘어 서아시아 정치·전쟁에 개입
- 기원전 6세기 말: 아케메네스 왕 다리우스 1세의 초원 원정
- 기원전 5~4세기: 흑해 그리스 도시와 교역, 왕족 쿠르간 조성
- 기원전 4세기: 아테아스 왕권의 성장
- 기원전 3세기 이후: 사르마티아 압력과 크림 중심 후기 정치체의 존속
